CS50x — Harvard

Depois de construir uma base em HTML, CSS e JavaScript, decidi ir além e comecei o CS50x, o curso introdutório de Ciência da Computação da Universidade Harvard. É um curso denso, mas extremamente completo: passa por C, Python, SQL, e agora estou avançando por JavaScript e desenvolvimento web mais aprofundado.

Mais do que aprender sintaxe de linguagens diferentes, o CS50 tem me ensinado a pensar como programador — testar hipóteses, traçar código manualmente antes de rodar, e entender o "porquê" por trás de cada solução, não só o "como". É um curso que exige disciplina e curiosidade, duas coisas que tento levar pra todos os meus estudos.

Linguagens estudadas até aqui

  • C
  • Python
  • SQL
  • JavaScript
